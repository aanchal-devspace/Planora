# ✈️ Planora

Planora is a basic Travel Planner web application built using HTML, CSS, JavaScript, Node.js, and Express.js.

It helps users plan a trip by adding trip details, creating activities, managing a packing checklist, and viewing a travel dashboard.

## Features

- Create a new trip
- Add trip details
- Plan daily activities
- Packing checklist
- Trip progress tracker
- Travel dashboard
- Data stored using Local Storage
- Basic Node.js & Express backend

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js

## Future Improvements

- User Login
- Weather Information
- Expense Tracker
- Hotel Suggestions
- Maps Integration
- Database (MongoDB)
- User Accounts

## Note

This project is a beginner-level college project created for learning Full Stack Web Development. The backend is kept simple using Node.js and Express.js.
